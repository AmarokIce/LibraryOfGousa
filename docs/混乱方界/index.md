**“盘古开天”**：  
盘古开天组织是以“改良危险岛屿环境”为目标而建立的民间组织，混乱方界内的组织只是分布，而组织的总部现在还未能得知在何处。  
组织内皆为不同岛屿的人类，也不存在不欢迎任何非人生物。  
截至目前，该组织已经修复混乱方界中 30% 的地貌，但尚不知晓该组织使用的是何种方式来修复岛屿。

**绿洲**：  
借由盘古开天组织的努力而唯一能够使得生物存活的区域。唯有此区域存在正常时间与天气。  
绿洲是一片广阔的草地平原，其正中间是一座小型城镇和一片湖泊，城镇内部有着大量物资并居住着盘古开天组织的成员。  
绿洲存在各种物资和畜牧生物。
